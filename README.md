# Python Utils Team

Набір невеликих Python-утиліт, створений в рамках лабораторної роботи 02.

## Модулі

- `src/calculator.py` - калькулятор (додавання, віднімання)
- `src/converter.py` - конвертер одиниць (км/милі, Цельсій/Фаренгейт)
- `src/password_generator.py` - генератор паролів

## Встановлення і запуск

1. Встановіть Python 3.10+
2. Склонуйте репозиторій: `git clone git@github.com:misha808/python-utils-team.git`
3. Перейдіть у папку проєкту: `cd python-utils-team`
4. Приклад запуску: `python -c "from src.password_generator import generate_password; print(generate_password())"`
